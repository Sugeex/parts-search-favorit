# Поиск автозапчастей и аналогов

React + Redux Toolkit + Tailwind CSS 4 (без TypeScript)

## Запуск

```bash
npm install
npm run dev    
```

## Как работает

1. Ввод артикула → `GET ?key&number` → из ответа берутся уникальные производители.
2. Клик по производителю → `GET ?key&number&brand&analogues=on` → таблица искомой детали и аналогов:
   название / производитель, цена, остаток.

- Цена — минимальная среди складов с остатком (поле `price` верхнего уровня по документации не используется).
- Остаток — поле `count` (сумма по всем складам). На экранах уже 640 px остаток показан строкой под названием.
- Обрабатываются: загрузка (спиннер), «ничего не найдено» (пустая структура в ответе), `{error}` от сервиса,
  сетевые сбои и HTTP-ошибки (с кнопкой «Повторить»), устаревшие ответы при быстрых повторных поисках.
- Доступность: подписанное поле, ошибка ввода у поля, озвучивание хода поиска (`role="status"`),
  видимый фокус, тёмная тема через `prefers-color-scheme`, `prefers-reduced-motion`.
